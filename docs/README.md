# ELORA — документация для AI-агента

ELORA — современный сайт бьюти-студии с онлайн-записью, портфолио работ, услугами, прайс-листом, отзывами, FAQ и Telegram-уведомлениями.

## Главная задача

Создать реально работающий production-ready сайт **ELORA** по четырём визуальным референсам:

- `ELORA_1_desktop_top.png` — Desktop, верх;
- `ELORA_2_desktop_bottom.png` — Desktop, низ;
- `ELORA_3_mobile_top.png` — Mobile, верх;
- `ELORA_4_mobile_bottom.png` — Mobile, низ.

Референсы — главный визуальный источник. Документация задаёт поведение и архитектуру.

## Жёсткий стек

- C#
- ASP.NET Core
- Visual Studio
- Razor Pages или ASP.NET Core MVC; предпочтительно Razor Pages
- SQLite
- HTML/CSS/vanilla JavaScript
- Telegram Bot API

Не использовать React/Vue/Angular, Docker, микросервисы, Kubernetes, Redis, RabbitMQ, PostgreSQL/MongoDB, JWT/refresh tokens или сложную инфраструктуру без отдельной необходимости.

## Запуск

Проект должен:

1. собираться в Visual Studio;
2. запускаться через F5 / Ctrl+F5;
3. открываться в браузере по локальному HTTPS/HTTP URL из `launchSettings.json`;
4. быть подготовлен к публикации на хостинг с публичным URL;
5. после публикации открываться обычной ссылкой в браузере без Visual Studio.

## Product Scope

Клиент может:

Услуга → мастер → дата → время → данные клиента → подтверждение → Telegram.

Владелец может:

- видеть записи;
- управлять услугами;
- управлять мастерами;
- задавать рабочие часы;
- блокировать даты;
- отменять/переносить записи;
- настраивать Telegram.

## Важный приоритет

1. Рабочая запись и защита от двойной записи.
2. Админ-панель.
3. Telegram и напоминания.
4. Точное соответствие дизайну референсов.
5. Дополнительная визуальная полировка.

AI не является обязательной частью MVP. Не добавлять AI только ради слова AI.
