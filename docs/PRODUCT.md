# ELORA — Product Scope

## Позиционирование

ELORA — сайт бьюти-студии с онлайн-записью и визуальным портфолио.

Основные категории:

- Маникюр
- Педикюр
- Ресницы
- Брови
- Волосы
- Тату

## Клиентский сценарий

1. Открывает ELORA.
2. Изучает услуги.
3. Смотрит реальные работы.
4. При необходимости изучает цены.
5. Нажимает «Записаться онлайн».
6. Выбирает услугу.
7. Выбирает мастера.
8. Выбирает дату.
9. Выбирает свободное время.
10. Вводит имя и телефон.
11. При необходимости подключает Telegram.
12. Создаёт запись.
13. Видит страницу подтверждения.
14. Получает Telegram-напоминание.

## Главная

Главная должна включать:

- Header;
- Hero;
- Услуги;
- Наши работы;
- Прайс-лист;
- Как записаться?;
- рекламный CTA;
- Отзывы;
- FAQ;
- Footer.

## Наши работы

Это обязательный отдельный раздел.

Он содержит:

- фотографии выполненных работ;
- категорию;
- при необходимости мастера;
- просмотр/фильтрацию по категориям.

Фильтры:

- Все
- Маникюр
- Педикюр
- Ресницы
- Брови
- Волосы
- Тату

## Дополнительные страницы

Разрешены:

- `/services`
- `/works`
- `/price`
- `/booking`
- `/about`
- `/contacts`
- `/faq`
- `/admin`

Они должны использовать ту же дизайн-систему ELORA.

## Админ-панель

- записи на день;
- услуги;
- цены;
- длительность;
- мастера;
- связь мастер → услуга;
- рабочие часы;
- блокировка дат;
- отмена;
- перенос;
- управление работами/портфолио;
- базовые настройки Telegram.

## Не входит в MVP

- онлайн-оплата;
- клиентские аккаунты;
- мобильное приложение;
- маркетплейс;
- сложная программа лояльности;
- сложная аналитика;
- Google Calendar;
- email-рассылки;
- multi-tenant SaaS;
- сложная AI-система.
