# ELORA — Telegram и напоминания

Telegram — канал уведомлений, а не база данных.

## Связь клиента

После записи пользователь получает возможность подключить Telegram.

Бот получает безопасный start-код и связывает chat_id с клиентом/записью.

Не доверять данным только из URL.

## Напоминания

Использовать ASP.NET Core `BackgroundService`:

1. найти активные записи;
2. выбрать записи примерно за 24 часа до визита;
3. проверить ReminderLogs;
4. отправить сообщение;
5. при успехе создать ReminderLog.

Проверять периодически.

## Сообщение

Содержит:

- услугу;
- мастера;
- дату;
- время;
- кнопки «Подтвердить», «Перенести», «Отменить».

Подтвердить → Confirmed.

Отменить → Cancelled и слот освобождается.

Перенести → безопасная страница ELORA для выбора нового слота.

## Если приложение выключено

BackgroundService не работает.

Для локального MVP приложение должно быть запущено.

Для production hosting сервис должен работать постоянно, иначе автоматические напоминания не выполнятся.

## Ошибки

Если Telegram временно недоступен:

- запись не отменяется;
- успешный ReminderLog не создаётся;
- следующий цикл пробует снова.
