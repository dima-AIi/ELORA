# ELORA — Алгоритм свободных слотов

## Вход

`ServiceId + MasterId + Date`

У услуги есть `DurationMinutes`.

## Проверки

1. услуга активна;
2. мастер активен;
3. мастер оказывает услугу;
4. дата не заблокирована;
5. существуют рабочие часы;
6. дата не в прошлом;
7. для текущей даты время уже не прошло.

## Генерация

Для рабочего диапазона, например 09:00–18:00, генерировать кандидатов с шагом 30 минут.

Слот подходит, если:

`slotStart + duration <= workEnd`

## Пересечение

`slotStart < existingEnd AND slotEnd > existingStart`

означает пересечение.

`Cancelled` записи не блокируют слот.

## Защита от double booking

Проверка только в JavaScript запрещена.

При создании записи backend повторяет проверку внутри SQLite transaction:

1. BEGIN IMMEDIATE;
2. найти пересекающиеся активные записи;
3. если найдена — ROLLBACK;
4. вернуть «Время уже занято»;
5. если нет — INSERT;
6. COMMIT.

## Перенос

Новый интервал проверяется тем же алгоритмом.

## Отмена

`Status = Cancelled`.

История сохраняется, слот становится доступным.
