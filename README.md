# ELORA — сайт студии красоты с онлайн-записью

> **Учебный проект-портфолио.** Студия, мастера, цены, отзывы и контакты на сайте
> вымышленные. Онлайн-запись и Telegram-уведомления — демонстрация функциональности,
> реальных услуг за ними нет.

**Демо:** https://elora2026.runasp.net

ASP.NET Core 10 (Razor Pages) + SQLite. Фронтенд — чистый HTML/CSS/JavaScript,
без сборщиков и фреймворков.

---

## Что внутри

- **Онлайн-запись** в 8 шагов: услуга → мастер → дата → время → данные клиента → подтверждение.
- **Защита от двойной записи** — транзакция SQLite, перенос и отмена визита по ссылке.
- **Админка** (`/admin`): записи, услуги, мастера, рабочие часы, закрытые даты, портфолио,
  отзывы, FAQ, вопросы, клиенты и возврат «пора напомнить».
- **Telegram**: два бота — публичный клиентский (`@elora_studio_bot`) и приватный
  админский (`@elora_admin_bot`); уведомления, напоминания, перенос и отмена кнопками
  в чате, вход в админку как Mini App.
- **AI-консультант** в секции «Часто задаваемые вопросы» на главной. Ключ провайдера
  живёт только на сервере, в браузер не попадает.

## Запуск локально

```bash
git clone https://github.com/dima-AIi/ELORA.git
cd ELORA/src
dotnet restore
dotnet run
```

Сайт откроется на `http://localhost:5080`.

### AI-консультант

Ключ провайдера (NVIDIA NIM) задаётся через `.env` — сам файл в репозиторий не
попадает, есть только образец:

```bash
cd ELORA.Web
cp .env.example .env      # затем вписать NVIDIA_API_KEY
```

Без ключа консультант честно отвечает, что не подключён (HTTP 503), вместо
выдуманных ответов. Подробности — в [docs/ELORA_AI_Design_Specification.md](docs/ELORA_AI_Design_Specification.md).

### База данных

Рабочая база (`App_Data/elora.db`) в репозиторий не попадает — она создаётся при
первом запуске из `Data/Sql/schema.sql` и заполняется демо-данными.

## Что не попадает в репозиторий

`.env` (ключи и токены), рабочая база с записями клиентов и резервные копии,
папки сборки `bin/` и `obj/`. Всё перечислено в `.gitignore`.
